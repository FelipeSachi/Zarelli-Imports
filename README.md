# Zarelli Essence Studio

Prompt para criação do site da ZARELLI IMPORTS

Crie um website premium, moderno e extremamente sofisticado para uma empresa chamada ZARELLI IMPORTS, especializada em perfumes importados originais sob encomenda e produtos importados em geral.

A identidade visual deve transmitir exclusividade, elegância e confiança, inspirando-se em marcas como Byredo, Tom Ford Beauty, Prada Beauty, Louis Vuitton, Apple e Aesop. O objetivo é que o visitante sinta que está navegando em uma marca de luxo, sem exageros ou elementos visuais poluídos.

Identidade Visual

Utilize exclusivamente a seguinte paleta de cores:

Grafite (cor principal)

#1F1F1F

Marfim (textos e áreas claras)

#F5F1E8

Champagne (detalhes e destaques)

#C9A86A

Evite preto absoluto (#000000), dourado metálico intenso, vermelho ou qualquer cor vibrante.

O design deve ser minimalista, com bastante espaço em branco (negative space), linhas finas e animações suaves.
